# ACV de una central geotérmica en la Sierra Nevada de Santa Marta

Presentación interactiva (HTML, CSS y JavaScript en un solo archivo, sin dependencias).

Programa de Ingeniería Energética, Universidad del Magdalena · Quiz 3 (Variante 11)

## Cómo verla
- Abre `index.html` en cualquier navegador, o
- Publícala con GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## Controles
- Flechas del teclado, barra espaciadora o botones ← → para cambiar de diapositiva.
- Deslizar en el celular.
- En «Etapas del ciclo de vida»: toca una etapa o pulsa **Auto**.
- En «Corte del terreno»: alterna entre método convencional y propuesta.
- En «Línea de tiempo»: usa el deslizador de años.
